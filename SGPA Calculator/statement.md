# Project Statement

## Problem Statement

Students have to manually calculate their percentages and SGPA every time
new exam marks come in, which takes time and is easy to get wrong. There's
no simple tool to just enter marks and see where you stand.

## Scope

This project is a command-line Python program that:

- Takes subject names, credits, and marks (CAT1, CAT2, TEE, Internal).
- Shows percentages, contribution breakdown, and SGPA.
- Shows the strongest and weakest subject.
- Tells you the marks needed in pending exams to hit a target SGPA.

It does **not**:

- Save data between runs.
- Connect to any website, app, or database.
- Have a graphical interface — it only runs in the terminal.

## Target Users

- Students who want to track their own SGPA during the semester.
- Students who want to know what marks they need to hit a target SGPA.
- Anyone learning Python who wants a simple example project.

## High-Level Features

- Enter subjects, credits, and marks with input validation.
- View exam-wise percentage.
- View contribution of each exam out of 100.
- View strongest/weakest subject.
- Calculate final SGPA.
- Plan target marks needed for a target SGPA.
